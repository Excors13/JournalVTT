World Codex 1.1.1 — исправление раннего сбоя загрузчика

Причина: scripts/bootstrap.js обращался к game.modules до инициализации Foundry.
Теперь загрузчик получает модуль на init, с резервным запуском на ready.
Основной runtime по-прежнему загружается через 2–3 секунды после ready.
Сетевые отказы повторяются с растущей паузой; одновременно выполняется один запрос.

Установка на сервер:
1. Остановите мир или Foundry.
2. Замените содержимое Data/modules/world-codex/ содержимым папки world-codex из этого архива.
3. Запустите Foundry, откройте мир. Все участники обновляют страницу с обходом кеша (Ctrl+Shift+R).
4. Через несколько секунд после загрузки мира проверьте кнопку кодекса и его настройки.

Публикация на GitHub:
1. Загрузите содержимое source/JournalVTT/ в корень Excors13/JournalVTT, сохранив структуру папок.
2. Actions → Publish Foundry release → Run workflow → версия 1.1.1.
3. Дождитесь успешного завершения. В Releases появятся module.json и world-codex.zip.
4. Обновите модуль в Foundry и перезагрузите страницы участников.
Не загружайте в корень репозитория внешние папки source/ или world-codex/.
В качестве альтернативы примените JournalVTT-1.1.1.patch к текущему main 8557f187.

Проверки: 65 тестов JavaScript и 6 тестов Python, проверка синтаксиса.
Порядок ранней загрузки воспроизведен локально; проверка на вашем живом сервере Foundry еще требуется.
Содержимое журналов и папок эта установка не удаляет.
