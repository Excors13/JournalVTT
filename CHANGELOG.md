# Изменения

## 1.2.2

- Игроки с уровнем «Владелец» в разделе создают журналы без подключённого мастера, если Foundry разрешает их роли создание журналов. Автор сразу сохраняет и редактирует запись.
- При создании запрашиваются права раздела. Если Foundry сохраняет владение только автору, права остальных участников применяются автоматически при следующем входе мастера, без ручного распределения.
- При отложенном применении проверяются автор, его владение и текущие права раздела. Присланные из игрокового документа уровни владения и снимки настроек не используются.
- Если служебная папка раздела ещё не создана, журнал временно хранится в корне и переносится автоматически при входе мастера.
- Ручное решение мастера по владению не перезаписывается отложенным применением. Нормально распределённые права повторно не сохраняются.

## 1.2.1

- Для журналов любого автора назначаются права текущего раздела; после создания проверяется фактическое владение. Дополнительное исправление отправляется только при расхождении. Роли «Игрок» и «Доверенный игрок» сохраняются.

- Кадрирование портретов прямо в редакторе: перемещение изображения, масштаб 25–400%, режимы заполнения и показа целиком, ползунки положения и сброс. Превью и просмотр используют одну рамку 5:6.
- Параметры кадра хранятся в записи для всех участников; исходный файл не изменяется. Масштаб и положение меняются без повторного запроса изображения.

- Каталог «Герои» открывается отдельной кнопкой с медалью рядом с дневниками игроков; основное меню разделов сохраняет прежние семь вкладок.
- Журналы героев используют обычные страницы, портрет, сведения, папки, ручной порядок и права по ролям. Поиск героев отделён от поиска основных разделов.
- Существующего персонажа можно перенести в «Герои» через поле «Раздел» редактора; UUID, страницы и содержание сохраняются.
- В настройках добавлены самостоятельные права «Героев». Если настроек ещё нет, берутся текущие права «Персонажей», без изменения существующих настроек.
- Исправления загрузчика, распределение прав игрокам и перетаскивание папок из 1.2.0 включены.

## 1.2.0

- Новая запись игрока и доверенного игрока всегда создаётся через активного мастера с полными правами раздела, даже если Foundry разрешает игроку создавать журналы напрямую.
- Мастер может восстановить права существующей записи кнопкой «Права раздела». Явное применение настроек исправляет рассинхронизацию записей в режиме прав раздела, не затрагивая ручные исключения.

- Мастер перетаскивает папки перед соседней папкой, после неё или внутрь неё; выбранное действие подсвечивается.
- Вложенные папки можно вернуть в корень раздела, в том числе когда в разделе нет журналов.
- Порядок папок сохраняется в sort документов Foundry; новое открытие кодекса сохраняет порядок, новые папки добавляются в конец.
- Перемещение папки и пересортировка соседей выполняются одним пакетным запросом. Журналы и вложенные папки сохраняют UUID, содержимое и права.
- Запрещены циклы вложенности, перенос в другой раздел, изменение служебных папок и перемещение игроками.

## 1.1.2

- Исправленный загрузчик опубликован из рабочего scripts/bootstrap.js в корне репозитория.

## 1.1.1

- Исправлен ранний сбой bootstrap.js: получение модуля и регистрация бинда выполняются на init, когда Foundry подготовил game.modules.
- Если входной файл пропустил init, загрузчик подключается на ready; если мир уже готов — запускается сразу с прежней задержкой.
- Добавлены проверки отсутствующего game, неготовой коллекции модулей, позднего появления модуля, повторного запуска и загрузки после ready.
- Основной код по-прежнему запрашивается одним файлом через 2–3 секунды после ready; сетевые повторы сохраняют ограничение одной попытки одновременно.

## 1.1.0

- Опубликована на GitHub из исходников 1.0.3.

## 1.0.3

- Основной клиентский код загружается одним файлом через 2–3 секунды после ready Foundry.
- Сетевые отказы повторяются с растущей паузой до минуты; одновременно выполняется одна попытка. Успех останавливает повторы, страница не перезагружается.
- Бинд регистрируется на init; запрос открытия до загрузки выполняется после восстановления.
- Настройки и обработчики безопасно подключаются после ready без повторного вызова глобальных хуков.
- Создание и исправление дневников выполняются пакетно; неизмененные документы не обновляются.
- Сборка без внешних зависимостей объединяет внутренние статические и динамические импорты; неизвестный синтаксис и статические циклы останавливают сборку.

## 1.0.2

- Выбор личной клавиши открытия из настроек модуля и кнопки клавиатуры в шапке; используется штатное управление Foundry 14.
- Кнопка каталога вынесена из блока создания журналов, который может быть скрыт у игроков; добавлены повторная установка на ready и поддержка изменённого каталога.
- Скрытие служебных папок учитывает идентификаторы документов и UUID, в том числе в отдельном окне браузера.
- ПКМ по записям и папкам: доступ, редактирование папки и удаление с подтверждением. Содержимое удаляемой папки переносится выше; записи не удаляются.
- Автор дневника может удалить свою запись через ПКМ.
- Обновление владения совместимо с числовой схемой Foundry 14: вместо null старые разрешения сбрасываются в уровень по умолчанию.
- Ошибка импорта клиентской части выводит понятное уведомление и сохраняется в API модуля для диагностики.

## 1.0.1

- Игроки и доверенные игроки с уровнем «Владелец» в правах роли для раздела видят кнопки создания журнала и папки, включая пустые папки.
- Если нативные права роли запрещают создание документов, активный мастер выполняет только разрешённое создание через проверенный запрос; текст журнала сохраняет сам игрок с обычной проверкой владения.
- Поиск перенесён над названием раздела.
- Кнопка добавления существующего журнала удалена. Мастер добавляет его перетаскиванием из стандартного каталога в корень раздела или папку.

## 1.0.0

- Разворачивание кодекса на рабочую область Foundry с восстановлением положения и размера; изменение размера не сбрасывает редактор.
- Переключатель бокового меню перенесён на разделитель; имена пользователей убраны из шапки.
- Записи и папки кодекса скрыты в стандартной панели журналов у игроков, включая владельцев.
- Кнопка штатного журнала Foundry доступна только мастерам.
- Поиск по доступным записям во всех разделах, история назад/вперёд, личный размер текста.
- Индикаторы владения в списке записей для мастера.
- Добавление существующих журналов с сохранением UUID, страниц, содержимого и прав; выбор текстовой страницы при чтении и редактировании.
- Скрытые метки и подписи карты с управлением видимостью для мастера.
- Небольшие уведомления «Задание дополнено» при выполнении цели или всего задания; учитываются права чтения, кодекс может быть закрыт.
- Личные закладки и принудительный показ игрокам не добавлялись.
