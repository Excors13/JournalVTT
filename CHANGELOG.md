# Изменения

## 1.0.0

- Разворачивание кодекса на рабочую область Foundry с восстановлением положения и размера; изменение размера не сбрасывает редактор.
- Переключатель бокового меню перенесён на разделитель; имена пользователей убраны из шапки.
- Записи и папки кодекса скрыты в стандартной панели журналов у игроков, включая владельцев.
- Кнопка штатного журнала Foundry доступна только мастерам.
- Поиск по доступным записям во всех разделах, история назад/вперёд, личный размер текста.
- Индикаторы владения в списке записей для мастера.
- Добавление существующих журналов с сохранением UUID, страниц, содержимого и прав; выбор текстовой страницы при чтении и редактировании.
- Скрытые метки и подписи карты с управлением видимостью для мастера.
- Небольшие уведомления «Задание дополнено» при выполнении цели или всего задания; учитываются права чтения, кодекс может быть закрыт.
- Личные закладки и принудительный показ игрокам не добавлялись.

## 0.2.1

- В манифест добавлена отметка совместимости с Foundry 14; верхний предел установки снят (14+).

- J по умолчанию открывает и закрывает кодекс; ввод в чате, полях и штатном редакторе не перехватывается.
- Защита от повторов удерживаемой клавиши и одновременных переключений окна.
- Закрытие сохраняет положение чтения и учитывает подтверждение отмены несохранённого текста.
- ПКМ по названию журнала в списке открывает штатное окно владения Foundry со списком игроков. Индивидуальные права сохраняются как ручные исключения.

## 0.2.0

- Итоговое оформление: компоновка BG3, угольная палитра и красные акценты.
- Порядок: Задания, Мир, Персонажи, Фракции, Места, Бестиарий, Карты.
- Штатные папки с созданием, переименованием и вложенностью; перемещение и сортировка журналов перетаскиванием.
- Сворачивание левой панели.
- Произвольные основные сведения и независимая правая колонка.
- Удалён отдельный интерфейс связанных записей; ссылки через @UUID в штатном редакторе.
- Изменение состояний целей прямо при чтении; зелёный и красный текст.
- Карты с масштабом, перемещением, полным экраном и 11 типами меток без подложки.
- Мини-просмотр связанного журнала и возврат к положению карты.
- Текстовые подписи: единый шрифт, жирный/обычный, курсив, размер, цвет, поворот, выравнивание, обводка.
- Права карт по ролям; личные дневники и ручные исключения владения сохранены.
- Необязательные демонстрационные записи и карта, миграция 0.1.0, упаковка Assets для GitHub Release.

Проверено автоматическими тестами и браузерным стендом с имитацией API. Настоящий мир Foundry не запускался; статус verified не заявляется.

## 0.1.0

Первая заготовка журнала, заданий и личных дневников с владением по ролям и GitHub Actions.
